# Agentic AI Calculator

A practice project demonstrating a simple Agentic AI workflow using LangChain and Cohere.

## Technologies Used

- Python
- LangChain
- Cohere
- Agentic AI
- Tool Calling

## How It Works

The AI agent receives a user query and can use a multiplication tool when required.

## Workflow

User Query → AI Agent → Tool Selection → Multiplication Tool → Final Response
